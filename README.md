# MILO: metrology-informed learning from index-coded ordinal labels

Code, run logs and figures for the manuscript
**"Learning the truth behind index-coded labels: metrology-informed neural forecasting with online risk control for air-quality warnings"** (submitted to *Neurocomputing*).

Everything is plain NumPy/SciPy: the package contains its own reverse-mode automatic-differentiation
engine (`ag.py`), so no deep-learning framework is needed. Every operator, layer, head and loss is
checked against numerical gradients (`test_ag.py`, output in `results/test_ag_output.txt`).

## Requirements

Python ≥ 3.10 with numpy, scipy, pandas, scikit-learn and matplotlib. Versions used for the paper:
Python 3.13.18, numpy 2.5.3, scipy 1.18.1, pandas 3.0.5, scikit-learn 1.9.1, matplotlib 3.11.2.
All runs used 2 CPU cores.

## Data

Daily ISPU records of the five DKI Jakarta monitoring stations (DKI1–DKI5), 1 Jan 2010 – 28 Feb 2025,
published by Dinas Lingkungan Hidup DKI Jakarta on Satu Data Jakarta and mirrored on Kaggle:
<https://www.kaggle.com/datasets/senadu34/air-quality-index-in-jakarta-2010-2021> (version 3).
Put `ispu_dki1.csv` … `ispu_dki5.csv` in `data/`, or point `MILO_DATA` to them:

```bash
export MILO_DATA="data/ispu_dki[1-5].csv"   # glob pattern
export MILO_RES="results/runs"               # per-run outputs (JSON metrics + NPZ predictions)
export MILO_OUT="results/tables"             # tables, statistics, figures
```

## Reproducing the paper

```bash
pip install -r requirements.txt
python test_ag.py                                   # gradient checks (worst scale-relative error 1.5e-7)
# experiment grid: 672 trained networks, resumable; run shards in parallel, e.g. 2 processes
python run_grid.py 0 2 main cs1 miss sweep backbone &
python run_grid.py 1 2 main cs1 miss sweep backbone &
wait
python analyze.py        # Tables 3-6 source CSVs, Wilcoxon/Holm, Friedman, Nemenyi (stats_main.json)
python rc_analysis.py    # decision rules with EB posterior (rc_all.csv)
python rc_post.py        # forecast-informed posterior (rc_post.csv; Table 7, Table B.3)
python make_tables.py    # all tables of the paper as markdown
python figs.py framework noise taskC reliability sweep misspec rc
```

On two CPU cores the full grid takes about 1.5 h; `main` alone about 40 min.

## Files

| File | Content |
| --- | --- |
| `ag.py` | autodiff engine, AdamW, fused censored noise-convolved Gaussian NLL (Eq. 6–7) |
| `nets.py` | MLP, GRU (fused BPTT kernel), TCN, Transformer; class, cumulative (CORAL) and latent heads |
| `ispu_core.py` | ISPU regulatory maps (P.14/2020, KEP-45/1997), inverse maps, rounding, noise scenarios S1/S2 |
| `data.py` | Tasks A/B/C, chronological splits, inputs, EB priors, posterior tables (Eq. 11), transition matrix (Eq. 12) |
| `methods.py` | all 13 methods: losses and published/true class distributions; copula aggregation (Eq. 9–10) |
| `train.py`, `metrics.py` | training with early stopping; NLL, RPS, ECE, Brier, QWK, F1, latent CRPS |
| `rc.py`, `rc_analysis.py`, `rc_post.py` | static and online risk control (Eq. 13), EB and forecast-informed posteriors |
| `analyze.py`, `make_tables.py`, `figs.py` | statistics, tables, figures |
| `results/runs/<group>.jsonl` | one JSON record of metrics per trained network, one file per experiment group (`main` 390, `cs1` 78, `miss` 36, `sweep` 108, `backbone` 60; 672 networks). `analyze.py` reads these archives, or the per-run files that `run_grid.py` writes to `results/runs/<group>/` when they exist. NPZ predictions, needed by `rc_analysis.py`, `rc_post.py` and the Task C figure, are regenerated by `run_grid.py` |
| `results/tables/` | aggregated tables, statistical tests and risk-control results used in the paper |
| `figures/` | Figures 1–7 at 300 dpi |

Method codes used in file names: `CE`, `LS`, `GCE`, `FwdT` (Forward-T), `CORAL`, `SORD`, `MSE` (MSE-reg),
`HetG` (Het-Gauss), `LD` (MILO-LD), `LD-flat`, `LT` (MILO-LT), `LT-noN` (w/o noise), `LT-noC` (w/o censoring),
`LT@s` (MILO-LT with assumed noise *s*).
